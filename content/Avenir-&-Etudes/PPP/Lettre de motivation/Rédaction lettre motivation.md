# Dans le cas d'une candidature suite à une annonce
exemple dans le cas d'un post de dev WEB

| Argumentaire sur MES compétance                              | Les compétence exigées      |
| ------------------------------------------------------------ | --------------------------- |
| projet                                                       | HTML                        |
| projet                                                       | CSS                         |
| Capable d'apprendre, autodidacte                             | Javascript                  |
|                                                              | Langage objet               |
| préciser notre niveau (B2), dire qu'on suit des cours, etc   | Anglais courant             |
| j'ai déjà travailler en équipe, j'ai déjà diriger des projet | leadership                  |
|                                                              | savoir travailler en équipe |
Ensuite, sélectionner les éléments les plus pertinent pour lettre.
puis rédaction avec les 3(+1) paragraphes

- Introduction : Expliquez brièvement pourquoi vous écrivez, le poste visé, et votre intérêt pour l’entreprise.
- Paragraphe 1 : Présentez votre parcours académique et les compétences techniques pertinentes.
- Paragraphe 2 : Mettez en avant vos qualités personnelles et expériences qui correspondent aux attentes de l’entreprise.
- Conclusion : Confirmez votre intérêt, proposez un entretien, et terminez avec une formule de politesse adaptée.
